## 📝 Overview
This Power BI dashboard provides an interactive and comprehensive analysis of **student performance, attendance, study habits, and overall academic standing**.  
It helps educators and analysts quickly identify key patterns, strengths, weaknesses, and correlations across multiple student attributes.

---

## 🔍 Dashboard Insights

### **1️⃣ Student Profile Panel**
- Gender  
- Absence Days  
- Self-Study Hours  
- Email  
- Total Students Count  

---

### **2️⃣ Academic Performance**
- **Total Marks** (Min–Max Slider)
- **Average Marks Gauge**
- **Overall Rank of Student**
- **Subject-wise Marks Table:**
  - Biology  
  - Physics  
  - Maths  
  - Geography  
  - History  
  - English  
  - Chemistry  

---

### **3️⃣ Top 5 Students**
A horizontal bar chart displaying the top 5 scoring students, helping identify peak performers at a glance.

---

### **4️⃣ Study Habits vs Attendance**
A line chart visualizing the relationship between:
- Self-Study Hours  
- Absence Days  

This helps identify if absenteeism impacts study habits or performance.

---

### **5️⃣ Additional Behaviour Insights**
- Part-Time Job Status  
- Career Aspiration (Dropdown Slicer)  

---

## 🎯 Purpose of the Dashboard
This dashboard aims to provide educators, students, and administrators with:
- Performance insights  
- Attendance impact evaluation  
- Subject-wise strength analysis  
- High scorer identification  
- Data-driven decision-making support

## 🚀 How to Use
1. Download the `.pbix` file from this repository.  
2. Open it using **Power BI Desktop**.  
3. Interact with slicers to explore student insights.  
4. Connect your own dataset if you want to customize the dashboard.
